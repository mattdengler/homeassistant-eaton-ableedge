# Security Policy

## Supported Versions

The following versions are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.0   | :white_check_mark: |
| < 0.0   | :x:                |

## Reporting a Vulnerability

Security vulnerabilities can be reported as issues on this repository.
All reported security issues will be looked at and address over other issues.
